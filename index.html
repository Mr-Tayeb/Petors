Good questions

No tech talk.
Just answers.

You're here to run a grooming business. The software should make that simpler, not become another job.

Will I have to pay monthly software fees?

We aim to keep ongoing costs close to zero by using lean infrastructure and free tiers where they fit. Optional domains, messaging and higher usage can have separate costs, which we'll explain upfront.

What does the free version include?

A limited starter copy of a grooming system designed for long-term use. It's a way to get started without purchasing a custom setup. Exact functions and maintenance arrangements will be confirmed before using a live version.

Can clients book when I'm closed?

Yes. A live system can let clients see real availability and request or confirm appointments even while you're busy or away. Automated replies can also help them get started.

What if I already have a website?

No problem. We can improve the booking experience, connect your existing site to a salon calendar, or build a more complete setup if needed.
